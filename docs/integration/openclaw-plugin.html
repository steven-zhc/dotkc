dotkc + OpenClaw plugin (typed tools)

Prefer typed tools over shelling out? Use the OpenClaw plugin: openclaw-dotkc.hczhang.com

What you get

  • Typed tool schema (predictable params/output)
  • Defensive redaction (extra guardrail against leaking secrets into model transcripts)
  • Cleaner OpenClaw tool allowlists/deny lists

Quick start

# install plugin (local link)
openclaw plugins install -l /path/to/openclaw-plugin-dotkc
openclaw gateway restart

# allow plugin tools
# tools.allow: ["dotkc"]
